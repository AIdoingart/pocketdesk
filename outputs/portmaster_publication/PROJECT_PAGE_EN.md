# PocketDesk

PocketDesk is a retro pocket desk for handheld Linux devices.

Built first for the R36S and dArkOS RE through PortMaster, it turns a small gaming handheld into an offline pixel PDA with a clock, notes, to-do list, agenda, calculator, timer, MTG counter, and settings.

## A Guided Learning Project

PocketDesk was directed by Gabriel Freitas as a guided learning project. Gabriel defined the concept, tested every build on real R36S hardware, shaped the interface, and decided the feature roadmap.

Codex assisted as a technical programming partner, helping implement the Love2D app, review bugs, package the PortMaster build, and document the process.

## Why PocketDesk Exists

The goal is simple: make the R36S feel like a small retro personal organizer, not just a game console.

PocketDesk is designed for:

- quick offline use
- physical controls
- small screens
- readable pixel UI
- local saving
- retro PDA energy

## Version 1.0 Tools

- Clock
- Notes
- To Do
- Agenda
- Calculator
- Timer
- MTG Counter
- Settings

## Technical Summary

- Engine: Love2D 11.5
- Target: R36S / dArkOS RE / PortMaster
- Input: D-pad, A/B/X/Y, L1/R1, Start
- Font: Press Start 2P
- Saves: local `save.txt`
