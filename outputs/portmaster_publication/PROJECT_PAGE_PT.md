# PocketDesk

PocketDesk e uma pequena mesa de ferramentas retro para portateis Linux.

Criado primeiro para o R36S com dArkOS RE via PortMaster, ele transforma o console em um PDA pixelado offline com relogio, notas, tarefas, agenda, calculadora, timer, contador de MTG e configuracoes.

## Um projeto de aprendizado guiado

PocketDesk foi dirigido por Gabriel Freitas como um projeto de aprendizado guiado. Gabriel definiu o conceito, testou cada versao no R36S real, ajustou a interface e decidiu o caminho das funcionalidades.

Codex ajudou como parceiro tecnico de programacao, revisao, empacotamento e documentacao.

## Por que o PocketDesk existe

A ideia e simples: fazer o R36S parecer um pequeno organizador pessoal retro, nao apenas um console de jogos.

PocketDesk foi pensado para:

- uso rapido e offline
- controles fisicos
- tela pequena
- interface pixelada legivel
- salvamento local
- energia de PDA retro

## Ferramentas da versao 1.0

## Resumo tecnico

- Engine: Love2D 11.5
- Alvo: R36S / dArkOS RE / PortMaster
- Entrada: D-pad, A/B/X/Y, L1/R1, Start
- Fonte: Press Start 2P
- Salvamento: `save.txt` local
