# PocketDesk 1.0 Release Notes

PocketDesk 1.0 is the first complete release candidate of the project.

## Highlights

- Built for R36S and PortMaster using Love2D 11.5.
- Fully offline toolkit.
- Pixel-style UI with physical controls.
- Local save data.
- Eight tabs: Clock, Notes, To Do, Agenda, Calc, Timer, MTG, Settings.

## Tools

- Clock: centered time, date, blinking colon.
- Notes: QWERTY virtual keyboard and formatting.
- To Do: task list, filters, priority, simple due options.
- Agenda: monthly calendar, events, event list, 3-day view.
- Calc: basic calculator with percent, square root, and memory.
- Timer: presets and minute adjustment.
- MTG: Normal/Commander life counter with solo Commander support.
- Settings: time, date, and color filter.
