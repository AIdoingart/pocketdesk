PocketDesk - Wallpaper

You can replace the PocketDesk background with any image.

To do that, place your image in this folder using exactly the same filename as the current file:

galaxy.png

If the filename is different, the program will not find the image.

The current image is black and white on purpose. PocketDesk applies a color filter over it inside the program. This lets the same image take on different tones, such as purple, blue, pink, green, night, or black and white, depending on the option selected in Config.

Recommendation:

- use a 640x480 image when possible
- prefer images with good contrast
- black and white images work best with the color filters
